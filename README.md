# MY WORKOUT BIBLE 💪

> 실사 운동 사진과 시작·끝 자세 가이드, 요일별 운동 계획, 중량·횟수·완료 기록, 해외·국내 트레이너의 운동별 고정 영상 링크를 제공하는 개인용 운동 웹앱

## 현재 운동 루틴 (월·화·목·금·토)

| 요일 | 성격 | 운동 수 | 총 세트 |
|---|---|---:|---:|
| 월 | 상체 A: 가슴 + 등 + 어깨 + 이두 | 7 | 16 |
| 화 | 하체 A: 레그프레스 + 덤벨 힙 쓰러스트 + 햄스트링 + 내전/외전 + 종아리 | 7 | 16 |
| 수 | 근력운동 휴식 / 회복 | — | — |
| 목 | 상체 B: 어깨 + 등 + 상부가슴 + 삼두 | 7 | 16 |
| 금 | 하체 B: 둔근 + 대퇴사두/햄스트링 + 내전/외전 + 종아리 | 7 | 17 |
| 토 | 전신 보완 / 부담에 따라 마지막 종목 생략 | 7 | 14 |
| 일 | 근력운동 휴식 | — | — |

헬스장 기구 기준으로 스미스 힙 쓰러스트와 케이블 글루트 킥백을 제외했습니다. 맨몸 글루트 브리지 대신 **덤벨 힙 쓰러스트**를 사용하고, **케이블 플라이, 힙 어덕션(이너타이)** 등을 보강했습니다. 레그컬은 **시티드 레그컬**, 어깨 측면은 **덤벨 사이드 레터럴 레이즈**, 카프레이즈는 **맨몸 스탠딩**입니다.

> 허리 통증·저림이 있거나 기구가 맞지 않으면 운동을 멈추세요. 첫 1~2주는 종목당 1~2세트부터 무리 없이 시작하고, 늘어난 운동량은 회복 상태에 따라 조절하세요.

## 운동 카드 기능

- **📷 실사:** Pexels에서 사용 허용된 운동 장면 사진을 표시합니다.
- **✨ AI 실사형:** 덤벨 힙 쓰러스트, 시티드 레그컬 등에 기존 생성 시안이 사용될 수 있습니다. 실제 촬영 사진이 아니며 자세 정확도를 보증하지 않습니다.
- **↔ 시작·끝:** Workout Guide의 종목별 실제 운동 동작에 맞는 1·3 프레임(일러스트)을 보여줍니다.
- **▶️ 운동법:** 유튜브 검색 화면을 거치지 않는 특정 영상 직행 링크. Jeff Nippard, Jeremy Ethier 등의 코칭을 기본으로, 황철순 선수 관련 영상은 보조 링크로 구분합니다. 정확히 같은 기구·동작이 아닌 영상에는 차이를 표시합니다. **한글 자막은 실제 제공 여부를 검증한 경우에만 보장할 수 있습니다.**
- **✍️ 기록:** 운동 날짜별 무게(kg), 반복횟수, 완료 체크 및 이전 기록 비교
- **📤 백업:** JSON 내보내기/복원 지원

## 이미지 출처 및 라이선스

- **Pexels 실사 사진:** [Pexels 라이선스](https://www.pexels.com/license/)는 웹사이트·앱에서 무료 사용을 허용하며, 운동 카드 내 사진 작가/출처로 이동하는 링크를 표시합니다. 사진은 자세 교과서가 아니라 운동 종목을 구분하기 위한 장면입니다.
- **동작 시작·끝 그림:** [Workout Guide](https://bryllim.github.io/workout-guide/) by Bryl Lim / Everkinetic — **[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)**. 개인 앱에서 사용하는 공개 그림 자료입니다.
- **추가 자료:** [Exercise data by RepDB](https://repdb.co/) — 해당 원본 제공자의 귀속·사용 조건을 준수합니다.
- **AI 생성 실사형 시안:** `assets/hip.webp`, `assets/legpress.webp`, `assets/legcurl.webp`, `assets/workout_design_mockup.webp`는 생성된 참고 디자인이며 **실제 운동선수·트레이너 사진이 아니고 운동 자세 검증용으로 사용하면 안 됩니다.**

## 데이터 보존

앱은 기존 기록과의 호환을 위해 브라우저 저장 키 `my-workout-bible-v2`를 유지합니다. **GitHub 업데이트가 기존 기록을 삭제하지는 않습니다.** 단, Safari 데이터 삭제·기기 변경·시크릿 모드 사용·브라우저 변경 시 기록이 사라지거나 다른 곳에 저장될 수 있습니다. 중요한 기록은 **기록·비교 → JSON 백업**으로 따로 저장하세요.
